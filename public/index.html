Deluxe Search

    Make Deluxe Search your default search engine

    Your search URL:

    • Chrome (computer): Settings → Search engine → Manage search engines → Add. Name it Deluxe Search, paste the URL above (the %s is where your search words go), then choose Make default.
    • Chrome (Android): visit this site and search once, then Settings → Search engine → pick Deluxe Search.
    • Firefox: right-click the address bar and choose Add "Deluxe Search", then pick it in Settings → Search.
    • Safari / iPhone: Apple doesn't allow custom default engines. Use Share → Add to Home Screen to get an app icon instead.
